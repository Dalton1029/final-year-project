# AWS / GCP deployment

## AWS
- React: S3 + CloudFront
- FastAPI: ECS Fargate or Lambda/API Gateway
- Node gateway: ECS Fargate
- Secrets: AWS Secrets Manager

## GCP
- React: Firebase Hosting or Cloud Storage + CDN
- FastAPI and Node gateway: Cloud Run
- Data: BigQuery
- Secrets: Secret Manager

Choose one cloud for a real deployment. Both paths are documented because the brief lists AWS and GCP.
